## 0. 一句话设计定位

**「悬浮在紫黑能量场中的磨砂控制台」**——一级工作台是一块接近正圆的半透明玻璃盘，静静悬在一片从右下角吞噬画面的紫黑立体褶皱能量流之上；9 个功能入口沿盘缘环绕，中心只留一句克制的「Release to Select」。整体气质：精密、安静、有纵深的未来科研仪器，而不是常见的紫色渐变 App。

### 1.2 背景：紫黑立体褶皱条带

- **走向**：全部条带从左上／上方流向**右下角消隐点**，呈扇形放射 + 强透视收敛。靠近 VP 处条带细密、间距压缩；远离 VP（左上）处条带变宽、间距张开。
- **数量**：主可见褶皱条带约 **14–18 条**（含被圆盘遮挡的部分）；视觉上能数清的亮面褶皱约 10–12 条。落地时取 **16 条**即可还原节奏。
- **单条宽度**：近 VP 端约 8–20 px，远端约 70–140 px（近大远小的反向：远端更宽）。
- **弯曲规律**：每条不是直线，而是带 **1–2 个 S 形波折**的飘带；波峰处形成「亮面翻折」，波谷处陷入近黑。用正弦横向扰动建模：`lateral = A(t)·sin(t·k + φᵢ)`，`t∈[0,1]` 为离 VP 的归一化距离。
- **明暗节奏**：亮面（淡紫／亮紫）与暗面（近黑紫）**交替出现**，一条褶皱内部自身也完成「高光 → 亮紫 → 中紫 → 深紫 → 近黑」的渐变，形成 3D 圆柱／丝绸般的体积感。相邻条带相位错开，避免整齐条纹感。
- **边缘高光**：每条亮面褶皱的**上缘**有 1–2 px 的冷白高光 `rgba(255,255,255,.45–.65)`；翻折处有更亮的窄带。这是「立体」而非「平面渐变」的关键，不可省略。
- **收敛规律**：角度按等角分布 `αᵢ = α_min + i·Δα`，但宽度和亮度按 `t` 做透视压缩；越接近 VP，条带越细、越暗、越密集，最终汇聚成黑色焦点。

## 2. 背景实现方案选型与理由

### 2.1 四种方案对比

| 方案 | 1:1 还原褶皱立体感 | 动态流动 | 性能 | 分辨率自适应 | 结论 |
|---|---|---|---|---|---|
| **SVG**（静态路径 + 渐变） | 中：可画飘带路径与渐变，但逐条手写 S 形与 3D 高光极繁琐，条数多时 DOM 重 | 弱：SVG 动画大量路径会掉帧 | 中 | 好 | 可作局部装饰，不适合主背景 |
| **CSS 3D**（transform 平面堆叠） | 低：平面 transform 做不出丝绸翻折的体积明暗 | 中 | 好 | 好 | 做不到原稿质感，排除 |
| **Canvas 2D**（程序化绘制条带） | **高**：逐条带绘制 S 形路径 + 多段渐变 + 高光，可精确控制节奏与收敛 | **好**：每帧重绘或相位偏移，流畅 | **好**：一次 clear + 16 条路径 | 好：按 DPR 缩放 | ✅ **推荐** |
| **WebGL / 着色器** | 最高：真实 3D 光照 | 最好 | 最好（GPU） | 好 | 能力过剩、工程复杂、小白难维护，暂不采用 |

### 2.2 推荐方案：Canvas 2D 程序化褶皱背景

**理由**：原稿的本质是「16 条带 S 形翻折、各自带体积渐变的飘带向 VP 收敛」。Canvas 2D 能用**一套参数方程**精确复刻这条规律，同时保留每帧微调相位的动态能力；单文件、无依赖、易调参、小白可维护。WebGL 上限更高但超出当前阶段需要。

> ⚠️ 明确禁止：用一张普通紫色渐变图 / 静态壁纸 / CSS `linear-gradient` 铺满来充当背景。那会得到「平面紫背景」，与原稿「立体褶皱能量场」完全不是一回事，是最常见的返工点。

### 2.3 可直接落地的实现思路（关键算法）

```
坐标：canvas 宽 W、高 H（按 devicePixelRatio 放大清晰度）
消隐点 VP = (0.97W, 1.02H)
条带数 N = 16
角度范围 α ∈ [55°, 145°]（从 VP 看向左上/上方扇形），等角分布 αᵢ

对每条 i：
  t ∈ [0,1]：0=近 VP，1=远端
  中心线：从 VP 沿方向 d(αᵢ)=(cos αᵢ, -sin αᵢ) 延伸
  横向扰动：lateral(t) = A·t·sin(t·k + φᵢ)     // A≈14%W，k≈6.5，φᵢ 每条错开
  半宽：w(t) = w0 + (w1-w0)·t                   // w0≈8px, w1≈0.06W
  两条边界 = 中心线 ± 法线·w(t)，闭合成飘带路径
  填充：沿带宽方向 linearGradient，色标：
    0%   #F6F0FB 高光   ── 亮面上缘
    18%  #E9D5FF
    42%  #A855F7 亮紫
    66%  #7C2FD0
    84%  #3B1066
    100% #08040F 近黑    ── 暗面
  相邻条带相位 φᵢ 交替偏移 π（实现亮/暗交替节奏）
  上缘再描 1px rgba(255,255,255,.55) 高光
  近 VP 端整体叠一层黑色径向渐变（收敛变暗）
```

- **渐变滤镜**：玻璃盘用 CSS `backdrop-filter: blur(22px) saturate(150%)`（见 §4）；Canvas 背景本身不加 blur，保留褶皱锐度。
- **DPR**：`canvas.width = W * dpr`，`ctx.scale(dpr,dpr)`，避免高分屏模糊。

### 2.4 克制动态效果

- 让 `φᵢ += ω·dt`（`ω ≈ 0.05 rad/s`），或整体 α 做 ±1.5° 的极慢摆动；**周期 20–28 秒**，线性无限循环。
- 只动相位/角度，**不动条数、不动宽度**，保证「流动」而不「闪烁」。
- 提供 `prefers-reduced-motion` 降级：静态绘制一帧即可。

## 3. 字体系统

避免 Inter / Roboto / 系统默认无性格字体；要有「科研仪器」的理性 + 一点点几何个性。

| 角色 | 字体 | 说明 |
|---|---|---|
| 显示 / 标题（英文数字） | **Sora**（Google Fonts，几何无衬线，有技术感但不俗） | 用于数值、状态词、大写标签 |
| 数据 / 编号 / 代码 | **IBM Plex Mono** | 审计编号、哈希、指标，等宽强化精密感 |
| 中文正文 | **PingFang SC → Microsoft YaHei → Noto Sans SC → sans-serif** 回退链 | 保证各平台可靠显示；中文不用花体 |
| 中文显示 | 同正文链，靠字重与字距区分层级 | 不额外引入中文字体文件，避免体积与版权问题 |

```css
--font-display:'Sora', 'PingFang SC', system-ui, sans-serif;
--font-mono:'IBM Plex Mono', 'PingFang SC', monospace;
--font-body:'PingFang SC','Microsoft YaHei','Noto Sans SC',system-ui,sans-serif;
```

**字号阶梯（px / 字重 / 行高 / 字距）**

| 层级 | 字号 | 字重 | 行高 | 字距 | 用途 |
|---|---|---|---|---|---|
| Display | 40 | 600 | 1.1 | -0.02em | 工作台标题 |
| H1 | 28 | 600 | 1.2 | -0.01em | 模块主标题 |
| H2 | 20 | 600 | 1.3 | 0 | 卡片标题 |
| H3 | 16 | 600 | 1.4 | 0 | 小标题 |
| Body | 14 | 400 | 1.6 | .01em | 正文 |
| Caption | 12 | 500 | 1.5 | .02em | 说明、tooltip |
| Mono | 12 | 500 | 1.4 | .06em | 编号、指标、哈希 |

> 层级靠**字重 + 字号**两档拉开即可，最多 3 种字重（400/500/600），不要堆 700+。

## 5. 动效规范

| 场景 | 时长 | 缓动 | 效果 |
|---|---|---|---|
| 背景褶皱流动 | 20–28 s / 循环 | `linear` | 相位 φ 极慢偏移，±1.5° 摆动 |
| 图标 hover | 180–220 ms | `cubic-bezier(.2,.8,.2,1)` | `scale(1.12)` + 紫色外发光 `0 0 18px rgba(168,85,247,.6)` + 线框提亮 |
| 图标点击反馈 | 80–100 ms | `ease-out` | `scale(.94)` 后回弹；触发时盘面涟漪 `radial` 扩散 300 ms |
| 名称 tooltip 浮出 | 140 ms | `cubic-bezier(.16,1,.3,1)` | 上移 6px + 淡入，玻璃小胶囊样式 |
| 选中 / 层级切换 | 380–420 ms | `cubic-bezier(.16,1,.3,1)` | 内圈文案淡出 → 目标二级页面从盘心放大淡入（scale .92→1） |
| 返回一级 | 320 ms | 同上 | 二级页面缩小淡出 → 盘面恢复 |

- 所有交互元素 hover 都给 `cursor:pointer` 与可见焦点环（键盘可达 `:focus-visible` 用 2px `--rc-magenta`）。
- 全局尊重 `prefers-reduced-motion: reduce`：关闭背景流动与涟漪，只保留 120 ms 淡入淡出。

## 6. 参考图 2–4 的二级页面设计语言（不改变一级工作台）

> 说明：本次共提供 4 张图，图 1 为一级工作台唯一基准；图 2/3/4 提供以下二级语言。任务中提到的「动态透视卡片」由图 2 的斜向透视堆叠衍生，不另设图片。这些语言**只在进入对应二级业务页后生效**，一级工作台永远是图 1 的样子。

- **图 2｜空间层叠卡片**：用于「历史审计项目 / 版本时间轴」页——多张磨砂项目卡片沿斜轴层层后退堆叠，横向滚动浏览；继承玻璃质感但用浅色留白背景，与一级的深底形成「进入档案室」的切换感。
- **图 3｜扇形展开**：用于「证据链 / 引用关系」页——以一个中心证据节点为轴，关联论文、数据、代码扇面放射展开，点击节点收拢/展开（180 ms）；只借放射结构，配色仍用本系统紫黑。
- **图 4｜深色精密科研线框**：用于「实验指标 / 数据审计详情」页——深黑底 + 细网格 + 技术标注线 + 单色（品紫）高亮数据点 + 等宽字体标签，呈现复现偏差、置信度等；是数据 dense 页的克制语言。
- **动态透视卡片（由图 2 衍生）**：用于「多方案结果对比 / 切换」页——卡片带轻微 3D 透视倾角，切换时前后卡片沿透视轴滑入滑出（400 ms），始终保留 1px 亮边与紫光晕，确保与一级玻璃语言同源。

## 7. 避免什么（降低返工）

1. ❌ 用普通紫色渐变 / 静态壁纸代替立体褶皱背景。
2. ❌ 把图 2/3/4 的元素混进一级工作台；它们只属于二级页。
3. ❌ 给环绕 9 个图标加常驻名称小字（原稿没有）；用 hover tooltip。
4. ❌ 用 Inter / Roboto / 默认无衬线做显示字体。
5. ❌ 玻璃盘只做半透明、漏掉模糊 + 亮边 + 多层阴影 + 环境色叠加。
6. ❌ 背景动画幅度过大导致闪烁；必须慢、必须可降级。
7. ❌ 乱改色板；所有紫以 §1.5 的 10 个变量为准，避免「又紫又亮又多色」。
