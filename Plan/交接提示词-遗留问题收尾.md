关键提醒：headless + --disable-gpu 是纯 CPU 渲染，这些数字只是相对参考，不等于真机 GPU 帧率。别一上来就大改代码。

你要做的：

2. 判断 7 FPS 的可能原因，给出你的分析。相关代码位置：bloom.css 419–422 行有一个 transition-property 包含 transform, width, height, opacity —— 注意 width/height 动画是性能反模式（会触发 layout），这很可能是元凶之一。
3. 如果确认是明确的性能反模式（例如动画了 width/height、常驻 will-change、展开瞬间挂载大量 DOM），做**最小范围修复**：把 width/height 动画改成 transform: scale()，把 will-change 限制在动画活动期，去掉不必要的 backdrop-filter。改完重新跑 FPS 脚本对比数据。
