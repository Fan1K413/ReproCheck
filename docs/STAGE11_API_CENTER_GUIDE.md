# 交付 2：API 管理中心使用说明（第十一阶段）

## 入口

侧栏「AI 模型服务」→「配置自己的模型 →」进入 `/settings/models`；或直接点击侧栏「模型管理中心」。
左侧 7 个分区：模型供应商 / API 凭据 / 我的模型 / 默认模型 / 任务模型分配 / 调用记录 / 使用统计。

## 配置流程（必须按顺序）

1. **添加凭据**：选供应商 → 填名称（可选）→ 填 API Key（password 输入框）→ 自定义接口填 Base URL → 保存。
   - 保存后前端立即清空明文输入框；列表只显示 `sk-a…xy` 形式的脱敏提示。
   - 自定义接口仅 HTTPS；私网地址、元数据域名、userinfo 被拒绝（`SSRF_BLOCKED`）。
2. **测试连接**（可选但推荐）：点击凭据行的「测试」。这是**真实调用**目标 API：
   - 会验证 Key 是否有效、Base URL 是否正确、模型是否存在、是否有权限、格式是否兼容、是否超时/限流；
   - 返回细分状态：`success` / `auth_failed` / `model_not_found` / `rate_limited` / `timeout` /
     `network_error` / `incompatible_format` / `provider_error`；
   - 绝不通过"Key 非空"判定成功。
3. **添加模型**：选供应商与凭据 → 填模型 ID（按供应商控制台实际值）→ 设置 temperature、超时、重试、最大 Token → 可标记默认/备用。
4. **默认模型**：设置默认与备用模型。备用只在任务绑定中显式指定后参与切换，并记录原因。
5. **任务模型分配**：为 PDF 解析、事实抽取、差异分析、失败诊断、RAG 问答、报告生成、材料总结分别选择主/备模型。
   - 未绑定任务继续使用服务端环境变量配置；不会静默把用户选择的模型换成其它模型。
   - 自动路由默认关闭；开启后也只在用户自己的模型中选择。
6. **调用记录 / 使用统计**：查看总次数、成功率、Token、平均/P95 耗时以及按供应商/模型/任务分组。

## 安全注意事项

- Key 只提交到授权后端；前端不写 LocalStorage / SessionStorage；创建后无法再次查看明文。
- 支持「撤销」（保留记录、停止使用）与「删除」（彻底移除密文）。
- 不同用户之间严格隔离：无法查看、修改、撤销他人的凭据（返回 404）。
- 服务端加密密钥 `MODEL_CREDENTIAL_KEY` 与数据库分离；缺失时拒绝保存用户 Key（503）。

## 供应商真实联调状态

适配层按官方 API 文档实现并通过协议级模拟测试；本环境没有真实 Key，界面上所有供应商都显示「未真实联调」。
用户保存自己的 Key 并执行连接测试后，该次测试是真实调用，但**供应商总体联调状态不会被程序自动改为"已联调"**，
避免把一次成功误标为全面验证。

## Site 版差异

同一页面在 Qoder Site 版可用；凭据由 Edge Function 服务端 WebCrypto 加密后写入托管数据库。
Site 版没有本地执行沙箱/PDF 解析运行时，模型调用测试与配置本身可用，但科研任务执行仍受平台限制。
