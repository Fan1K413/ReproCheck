# 新手引导与任务优先首页说明

日期：2026-11-24  
相关文件：`frontend/src/workbench/WorkbenchPage.tsx`、`frontend/src/ux/FirstRunExperience.tsx`、`frontend/src/workbench/RadialWorkbench.tsx`、`frontend/src/workbench/EntryLauncher.tsx`  
相关路由：`/`、`/?what=1`、`/start/reproduce`、`/manual`

## 1. 设计目标

第一次打开 ReproCheck 的人，通常不知道：

- 这软件的“复现审计”到底要做什么；
- 九个图标分别代表什么；
- 先建项目、先传论文，还是先配 AI；
- 配错 API 会怎样；
- 做完一步后该去哪。

本轮不删除专业入口，而是把“任务目标”放在第一层，把“功能模块”退到第二层。这样既满足新用户，也不破坏原有径向工作台与花瓣二级交互。

## 2. 首次进入的真实行为

### 状态判断

`WorkbenchPage` 读取：

- `rc:onboarding:v1`：`done` / `skipped` / 不存在；
- 查询参数 `what=1`：从其他页面进入时，直接打开“我想做什么”目标页。

| 场景 | 初始界面 |
|---|---|
| 无 onboarding 键，无 `what=1` | `FirstRunExperience` 欢迎页 |
| 无 onboarding 键，有 `what=1` | 直接进入目标页 |
| 已 `done` / `skipped`，无 `what=1` | 径向工作台 |
| 已 `done` / `skipped`，有 `what=1` | 目标页；完成后回到工作台 |

### 欢迎页

展示六张能力卡：论文材料、数据与代码、复现步骤、运行记录、结果对照、审计报告。
主按钮“下一步：选择我想做的事”；次链接“先看中文使用手册”。
右侧用轨道图形表示“论文 → 数据/代码/实验/证据/报告”的关系，不放入真实数据，因此不构成模拟业务数据。

### 目标页

五个目标：

1. 我想复现一篇论文 → `/start/reproduce`；
2. 我想管理已有项目 → `/projects`；
3. 我想检查一次实验结果 → 选择项目 → 结果对照；
4. 我想生成或查看报告 → 选择项目 → 审计报告；
5. 我还不知道怎么用，带我看看 → 一分钟四步讲解。

目标页底部提供“用示例了解流程”和“打开完整手册”。示例页是真实存在的演示路由 `/demo/audit`，不是伪造的项目数据。

### 一分钟讲解

用四步卡片说明：建项目 → 加论文 → 拆步骤 → 出报告。
明确写出“没有 API 密钥也能先管理项目和材料；AI 整理是可选增强”。

## 3. 返回用户的工作台

保留原有深墨紫径向背景、576px 环形玻璃透镜、9 个入口、花瓣二级卡。

新增轻量顶栏：

- “我想做什么”：重开目标页；
- “中文手册”：进入手册；
- “使用帮助”：当前页帮助抽屉（工作台使用 `home` 帮助）。

入口名称已从技术词改为任务语言：

|---|---|
| 检查论文问题 | 检查论文问题 |
| 我的科研项目 | 我的科研项目 |
| 论文与材料 | 论文与材料 |
| 做一次复现 | 做一次复现 |
| 检查标准 | 检查标准 |
| 结果与交付 | 结果与交付 |
| 差异与数据检查 | 差异与数据检查 |
| 团队与连接 | 团队与连接 |
| 连接 AI 助手 | 连接 AI 助手 |
| 规划 DAG（复现步骤与脚本） | 复现步骤清单 |

## 4. 已验证的真实行为

来自 `.screenshots/usability/round2/usability-verify-round2.json`：

- 首次进入：`iconWallCount = 0`，欢迎页 H1 正确；
- 点“下一步”后目标页 H1 正确；
- 点“我想复现一篇论文”后进入 `/start/reproduce?step=1`，并写入 `rc:onboarding:v1=done`；
- 点“先跳过”后工作台显示 9 个入口，状态 `skipped`；
- 刷新后仍在工作台（需注意：测试脚本本身不能每次清空状态；最终复验已修正该测试隔离问题）；
- 工作台点“我想做什么”直接到目标页，不再出现欢迎页；
- 花瓣展开 + ESC 关闭；
- 工作台帮助抽屉 + ESC + 焦点回到触发按钮；
- 1440/390/768/1920 横向溢出均为 0（当前已测页面）。

## 5. 未完成

- 首次引导目标分支“检查实验结果 / 生成报告”只做了代码审查，没有逐个点击完整走查；下一轮应补。
- 390 宽度首次引导的视觉观感尚未单独截图验收；现有宽度检查主要覆盖工作台、四步引导、API、手册。
- 外部真实新用户（非开发者）尚未独立使用；见 `USABILITY_REAL_USER_TEST_REPORT.md`。

## 6. 后续可做但不本轮擅自做

- 把工作台中央也改成 WorkBuddy 式“输入一句话”入口；
- 用最近项目数据生成个性化目标卡；
- 在目标页加入“上次没做完”的断点续做；
- 为九个入口增加首次使用时的“只显示三个推荐入口”模式。

以上均需用户确认，因为会改变现有工作台的产品定位。
