## 1. 调研目标

验证第六阶段产品升级方向是否来自真实科研需求，而非开发者想象：

1. 科研复现过程中，哪些环节最耗时、最易出错？
2. 跨材料（论文 / 代码 / 配置 / 实验记录）不一致是否真实高频发生？
3. 多人协作复现、导师审核学生复现过程是否是真实需求？
4. 科研人员对自动化审计工具的接受度与信任门槛是什么？
5. 对材料上传、隐私、数据安全的顾虑具体是什么？
6. 现有科研工具链（GitHub / Jupyter / 文献管理 / 实验记录）如何与审计平台衔接？

## 2. 目标用户与抽样

第六阶段适用领域限定：**机器学习、计算机科学、数据科学**。不急于扩展其他学科。

| 用户群 | 抽样目标 | 招募渠道 | 核心关切假设（待验证） |
|---|---|---|---|
| 高校研究生（硕博） | 8–12 人 | 本校 ML/CS 实验室、研究生群 | 复现论文耗时、参数找不到、导师要求 |
| 高校科研教师 / 导师 | 3–5 人 | 学院教师、合作实验室 PI | 审核学生复现质量、项目进度追溯 |
| 机器学习研究人员（含工业界） | 4–6 人 | 开源社区、论文作者邮件 | 参数对照准确性、环境复现、基准积累 |
| 实验室科研助理 | 2–4 人 | 实验室管理员 | 材料整理效率、批量处理、格式兼容 |
| 科研项目负责人 | 2–3 人 | 课题组负责人 | 多项目监管、证据链、正式报告 |
| CS/DS 研究团队（整组试点） | 1 个实验室（5–10 人） | 有 ML 论文复现需求的合作实验室 | 端到端协作流程 |

抽样原则：优先覆盖「正在复现或近 6 个月复现过论文」的人；兼顾成功与失败复现经历；避免只访谈熟人导致的偏差。

## 4. 问卷设计（v1 草案）

问卷全文见附录 A。覆盖任务书要求的 10 个问题维度：

1. 论文 / 代码 / 实验配置的常规管理方式（多选：文件夹、Git、文献管理软件、笔记软件、无固定方式）；
2. 复现最耗时环节（排序：找代码、配环境、对齐参数、跑实验、调差异、写记录）；
3. 是否遇到过论文与代码参数不一致（频率量表 + 开放举例）；
4. 是否需要跨多个文件寻找实验依据（频率量表）；
5. 实验记录完整性自评（Likert 5 点）；
6. 是否需要多人共同复现（是/否 + 当前协作方式）；
7. 是否需要导师审核复现过程（是/否 + 当前审核方式）；
8. 当前使用的科研软件（多选 + 填空）；
9. 对自动化审计工具的意愿（Likert 5 点 + 信任前提条件多选）；
10. 上传与隐私顾虑（多选：未发表数据泄露、代码保密、合规、模型训练使用、无顾虑）。

问卷末尾收集：领域、角色、复现经验年限、是否愿意接受访谈 / 试点（联系方式单独存储，与分析数据分离）。

## 5. 访谈与试点伦理

- 知情同意：说明用途、数据匿名化方式、可随时退出；访谈录音需单独同意。
- 隐私：不要求受访者上传未发表材料；试点材料须获得实验室 PI 书面同意。
- 数据安全：试点数据按 `DATA_GOVERNANCE_POLICY.md` 分类管理；联系方式与分析数据分离存储。
- 诚实报告：样本量、招募方式、未完成项如实写入报告；不允许用开发者自测冒充用户数据。

## 6. 试点方案与指标

### 6.1 试点流程（与产品主流程一致）

研究人员创建项目 → 上传论文和材料 → 运行科研审计 → 查看复现缺口 → 生成复现任务 → 完成实验验证 → 人工复核 → 生成报告。

### 6.2 采集指标（全部来自真实埋点与人工记录，禁止估算）

| 指标 | 定义 | 采集方式 |
|---|---|---|
| 首次使用完成率 | 新用户在无人协助下完成「创建项目→上传→审计→查看结果」的比例 | 操作审计轨迹 + 观察 |
| 材料上传成功率 | 上传成功数 / 尝试数 | 后端日志 |
| 解析失败率 | 解析失败材料数 / 已解析材料数，按格式分桶 | parse_tasks 状态 |
| 审计结果采纳率 | 被用户「确认」的 finding / 总 finding（含误报标记） | 反馈体系记录 |
| 人工复核时间 | 每条 finding 从提交复核到审结的时长 | 审计轨迹时间戳 |
| 任务完成时间 | 复现任务创建到完成的时长 | 任务状态时间戳 |
| 用户反馈 | 结构化反馈 + 访谈纪要 | 反馈体系 + 访谈 |
| 实际使用障碍 | 阻断性问题清单（按 P0–P3 分级） | 观察 + 反馈 |

### 6.3 试点准入条件

- 至少 1 个有 ML 论文复现需求的实验室同意参与；
- 平台通过第六阶段专项测试中的权限与隔离测试（见 STAGE6_TEST_REPORT.md）；
- 明确数据保留与删除承诺，试点结束后按约定清理或导出。
