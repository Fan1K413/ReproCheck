## 三、不同研究领域的适用性

| 领域 | 适用能力 | 可审计深度 | 说明 |
|---|---|---|---|
| ML/DL | 代码 AST 解析、超参数提取、配置一致性 | 静态（无运行时） | 需要 LLM 做论文-代码映射 |
| CV | 同上 + 图表反向验证 | 静态 | 真实模型执行需要 GPU |
| NLP | 同上 | 静态 | 检索系统组件无法静态审计 |
| BioInfo | 同上 | 静态 | 依赖链复杂，静态分析有限 |

## 四、不可避免的局限

1. **真实 LLM 抽取质量**：本环境无 API Key，无法评估。有 Key 后需要单独执行 10+ 真实 PDF + 代码项目来抽取 Precision/Recall。

2. **运行时行为审计**：需要 gvisor 或 rootless_docker 隔离环境，本环境无法构建。

3. **OCR 质量**：扫描件 PDF 无法处理，需要 Tesseract + OpenCV。

4. **基准数据集**：ReproCheck 自己没有 "金标准" 数据库——这是下一阶段应该建设的基础设施。
