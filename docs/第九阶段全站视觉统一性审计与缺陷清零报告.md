## 二、测试方法与真实性边界

1. 路由审计使用本机原生 Chromium + Playwright，不用远程 Browser Use 的裁切截图替代产品证据。
2. 每个路由记录状态码、`mainOpacity`、视口与文档宽度、页面文本、Canvas、图片、iframe、交互目标尺寸、逐路由 runtime errors。
3. 截图以真实页面 `fullPage` 截取，再仅用于排版成联系表；联系表不修改、不重绘、不替换产品画面。
4. 根工作台交互通过真实鼠标、键盘、拖动、Esc、SPA 导航和移动视口完成，不以 API 调用替代界面行为。
5. 科研路径使用真实新建项目、上传合成 Markdown/CSV/Python/requirements、真实解析任务、真实规划、真实运行、真实报告与历史重开。
6. 性能使用页面内原生 `requestAnimationFrame` 帧间隔、`PerformanceObserver` Long Tasks、CDP Performance、导航时序、JS Heap 和 DOM counters；没有用固定等待秒数伪造 FPS。
7. 本轮不做“截图好看即通过”的判断：每页视觉评分绑定最终联系表和具体扣分项。

未覆盖：Safari/Firefox、真实 iPhone/Android 真机、屏幕阅读器全站无障碍、独立安全渗透测试、生产静态服务器性能。报告明确保留这些边界。
